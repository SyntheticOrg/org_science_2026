# D4 Model dependence and change

Use when relevant to the study's assumptions. Follow the shared principles in [study protocol](../../../study-protocol/SKILL.md).

Consider how the inference depends on the selected model and access conditions, especially when observations are collected over time or claims extend beyond the configuration examined.

Record available model identifiers, configuration, and access dates. A repeated reference setting or another model can provide useful evidence when it addresses a stability or generality claim; neither is a compulsory extension of every study.

An unchanged identifier does not guarantee unchanged behaviour, and a difference across models does not identify which property caused it. State the conditions actually examined and any uncertainty about stability or transfer.
