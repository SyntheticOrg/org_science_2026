# B6 Responses to changed arrangements

Use when relevant to the study's assumptions. Follow the shared principles in [study protocol](../../../study-protocol/SKILL.md).

Consider this when a new arrangement changes what behaviour the mechanism predicts, particularly in a familiar task. Ask whether the construction can distinguish response to the changed setting from repetition of a learned pattern.

Possible evidence includes changes to incentives, labels, information, or decision rights chosen to separate competing accounts. Prefer a comparison with a clear implication for the research question over a universal perturbation checklist.

Unchanged behaviour can reflect template-following, weak incentives, misunderstanding, or a genuinely stable response. State what the comparison distinguishes and which counterfactual conditions remain unsupported.
