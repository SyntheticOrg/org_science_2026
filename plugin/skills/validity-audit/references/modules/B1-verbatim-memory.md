# B1 Memory and access to prior information

Use when relevant to the study's assumptions. Follow the shared principles in [study protocol](../../../study-protocol/SKILL.md).

Consider this when the explanation depends on retention, forgetting, attention, or accumulated knowledge. Ask what information remains available to members and how that differs from what the argument assumes.

Possible evidence includes inspection of information actually available at decisions, its use over time, or comparisons between justified memory constructions. A recall check or human benchmark can help when relevant; no particular turn window or notepad size is prescribed.

A context window, retrieval system, and notepad implement different forms of access to information. Verify the chosen operationalisation and account for other paths by which information can persist. An outcome change after a memory intervention supports a narrower claim than proof of human-like cognition.
