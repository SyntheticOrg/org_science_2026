# B3 Reasoning configuration as a construction choice

Use when relevant to the study's assumptions. Follow the shared principles in [study protocol](../../../study-protocol/SKILL.md).

Consider this when reasoning configuration could affect the behaviour the explanation depends on. Ask which settings the selected model actually supports and why the chosen configuration suits the task.

Possible evidence includes behaviour under a justified alternative configuration, observations of task performance, or sensitivity of the proposed mechanism. Verify that a requested setting changes the actual configuration before interpreting the comparison.

Reasoning effort is not automatically a measure of human cognitive effort or member heterogeneity. Report the operational choice, what influenced it, and the conditions under which its consequences were examined.
