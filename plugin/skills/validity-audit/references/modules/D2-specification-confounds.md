# D2 Specification and measurement effects

Use when relevant to the study's assumptions. Follow the shared principles in [study protocol](../../../study-protocol/SKILL.md).

Consider whether construction choices could produce the finding through a path other than the proposed explanation. Ask what should change in a comparison and which features need to remain comparable.

Inspect implemented information flows, instructions, decision opportunities, and measurements. A wording comparison, alternative operationalisation, or negative control can help when it has a clear implication for the suspected confound; these are options rather than a compulsory set of tests.

Dependence on wording or measurement raises a question about interpretation, not an automatic diagnosis. Explain what the chosen check establishes, which alternatives remain, and how any construction changes affect the scope of the result.
