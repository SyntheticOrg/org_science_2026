# B5 Information integration and task competence

Use when relevant to the study's assumptions. Follow the shared principles in [study protocol](../../../study-protocol/SKILL.md).

Consider this when members must combine information, interpret evidence, or perform calculations that matter to the outcome. Ask which capabilities the explanation assumes.

Possible evidence includes decisions with known answers, use of information in interaction, or a comparison in which the same task information is made available differently. Select a check that separates the capability question from the organisational comparison as far as the design permits.

Unexpected errors may reflect model capability, information delivery, measurement, or interaction, and these can jointly affect the outcome. Establish what failed before attributing the result to the arrangement or claiming that a communication change repaired the mechanism.
